# README Creation Prompt

Use the following instructions to generate a consistent `README.md` for any new folder in this repository.

---

## Instructions

Analyze the files in the target directory and generate a `README.md` following this structure:

### 1. Title (H1)
- Format: `# LangChain [Topic Name]`
- Use a clear, descriptive title based on the primary focus of the folder.

### 2. Introduction
- A brief paragraph (2-3 sentences) explaining the purpose of the directory and the core concepts explored.

### 3. "What We Learned" Section (H2)
- Use H3 subheadings for each major concept or technique.
- Under each H3, include a bulleted list of specific learnings, implementation details, or libraries used.
- Focus on practical applications (e.g., "Using LCEL", "Implementing RAG", "Schema Validation").

### 4. "Key Files" or "Folder Structure" Section (H2)
- Provide a list of important files in the directory with a one-line description of what each file demonstrates.

---

## Example Pattern

```markdown
# LangChain Example Folder

This directory demonstrates how to [primary goal]. It focuses on [key technology 1] and [key technology 2].

## What We Learned

### 1. [Concept 1]
- [Specific detail 1]
- [Specific detail 2]

### 2. [Concept 2]
- [Specific detail 1]

## Key Files
- `example.py`: Demonstrates [feature].
```
